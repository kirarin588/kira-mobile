# kira 2人の勉強（スマホ・iPad 用）

Anki のアドオン「kira」が Supabase に送っている2人の今日の記録（スコア・目標・いま勉強中か・勉強計画・学習の流れ・進捗率・復習のバランス）を見るだけのページ。

- 開いたらルームコードを入れる（その端末の localStorage にだけ保存。ページには書かない）
- Supabase の鍵は公開用（publishable）。ルームコード（x-kira-room ヘッダー）がないと何も読めない
- ホーム画面に追加すると、アプリのように開ける

## desk.html（机の上に置くダッシュボード）

使っていないタブレットを横向きに置いて、ずっと表示しておくための画面。見るだけ。

- 大きな時計（秒の輪つき）・日付・試験までの「日＋時:分:秒」のカウントダウン
- 2人それぞれ：今日のスコア（変わったら点滅して「+12」）・いま勉強中か・輪（毎日の目標／今日の計画／交互 を切り替え）・新規／復習／Anki の時間／連続日数・今日の勉強計画
- 真ん中：VS（リード・一番乗り）、この7日のスコアと勝ち数、進捗率
- 下：2人の今日の学習の流れ（流れる文字）
- 自分が ⏱（ストップウォッチ・ポモドーロ・タイマー）で測っている間は「集中モード」：タイマーを大きく出して、お知らせは止める（スコアと計画は出したまま）。勉強 ⇄ 休憩・時間切れで、画面いっぱいのお知らせと音
- 40秒ごとに、自分の数字（いまの科目の進捗率・今日の枚数・目標・今日の勉強計画の全体・試験までの日数とペース など）を真ん中に大きく出す
- スマホ（幅600px以下・横向きのスマホ）では1画面に1枚：自分／VS（測っている間はタイマー）／相手 を、左右のスワイプか下のタブで切りかえる。時計はいつも上。タイマーを始めるとタイマーの画面へ自動で移り、ほかの画面では右上に小さなタイマーを出す
- 相手が計画の項目を終えた・目標を達成した・勉強を始めたときに、お知らせと紙吹雪
- 背景は時間帯で色が変わる。夜中（1〜5時）は暗くする。焼き付き防止に1分ごとに少しずらす
- 画面を一度押すと、対応している端末では画面をつけたままにする（iPad は自動ロックを「なし」にするのが確実）
- ルームコードはスマホ用ページと同じ保存場所（同じ端末なら入れ直さなくていい）
